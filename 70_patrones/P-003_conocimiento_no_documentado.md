# Propósito

Este documento define el patrón organizacional **Conocimiento no Documentado**.

Describe las condiciones bajo las cuales ATÓMICA puede formular la hipótesis de que parte del conocimiento crítico de una organización depende de la memoria individual y no del sistema organizacional.

---

# Definición

Existe este patrón cuando el conocimiento necesario para operar, decidir o mantener la continuidad del negocio no se encuentra suficientemente documentado ni resulta accesible para la organización.

El conocimiento existe.

La organización no puede reutilizarlo de forma fiable.

---

# Naturaleza

Este patrón representa una limitación en la capacidad de aprendizaje y continuidad organizacional.

No implica ausencia de conocimiento.

Implica ausencia de conocimiento compartido.

---

# Objetivo metodológico

Identificar situaciones donde el conocimiento organizacional permanece implícito y depende excesivamente de las personas que lo poseen.

---

# Manifestaciones habituales

El patrón puede manifestarse mediante situaciones como:

- procedimientos únicamente conocidos por determinadas personas;
- documentación incompleta;
- documentación obsoleta;
- incorporación lenta de nuevos empleados;
- pérdida frecuente de conocimiento tras cambios de personal;
- respuestas distintas para un mismo procedimiento.

Estas manifestaciones no constituyen evidencia suficiente por sí mismas.

---

# Observaciones relacionadas

El patrón puede apoyarse en observaciones relativas a:

- documentación disponible;
- accesibilidad del conocimiento;
- actualización documental;
- procesos de transferencia;
- formación interna;
- continuidad operativa.

---

# Hipótesis relacionadas

Este patrón puede reforzar hipótesis como:

- dependencia de persona clave;
- aprendizaje insuficiente;
- baja resiliencia operativa;
- transferencia deficiente del conocimiento.

---

# Capacidades relacionadas

Habitualmente aparece asociado a capacidades relacionadas con:

- gestión del conocimiento;
- aprendizaje organizacional;
- continuidad operativa;
- desarrollo de personas;
- documentación.

---

# Fragilidades relacionadas

Este patrón puede contribuir al fortalecimiento de diversas fragilidades organizacionales.

No existe una relación exclusiva con ninguna de ellas.

---

# Evidencias que incrementan la confianza

Ejemplos:

- ausencia de procedimientos documentados;
- documentación desactualizada;
- inexistencia de repositorios compartidos;
- pérdida recurrente de conocimiento;
- dependencia de explicaciones verbales.

---

# Evidencias que reducen la confianza

Ejemplos:

- procedimientos actualizados;
- repositorios accesibles;
- documentación utilizada regularmente;
- revisiones periódicas;
- transferencia sistemática del conocimiento.

---

# Restricciones

Este patrón no permite concluir que la organización carezca de conocimiento.

Únicamente indica que dicho conocimiento podría no encontrarse suficientemente estructurado, compartido o preservado.

# Conclusión

El patrón **Conocimiento no Documentado** identifica una vulnerabilidad estructural relacionada con la conservación y transmisión del conocimiento organizacional.

Su detección permite formular hipótesis sobre la capacidad de la organización para aprender, mantener la continuidad y reducir la dependencia del conocimiento tácito, preservando en todo momento el carácter provisional del modelo organizacional.
