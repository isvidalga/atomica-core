# Propósito

Este documento define el proceso metodológico mediante el cual ATÓMICA detecta patrones organizacionales.

No define algoritmos de implementación.

No define reglas específicas para cada patrón.

Describe el proceso general que deberá seguir cualquier mecanismo de detección.

---

# Principio fundamental

Un patrón nunca aparece de forma inmediata.

Es el resultado de la acumulación de conocimiento sobre una organización.

La detección constituye un proceso de inferencia progresiva.

Nunca una clasificación instantánea.

---

# Punto de partida

La detección comienza cuando el modelo organizacional contiene suficiente información para evaluar posibles regularidades.

Dicha información puede proceder de:

- declaraciones;
- observaciones;
- hipótesis;
- capacidades;
- fragilidades;
- evidencias;
- relaciones;
- evolución temporal.

---

# Fases de detección

Toda detección sigue las mismas etapas.

```
Observaciones

↓

Construcción del modelo

↓

Hipótesis

↓

Evaluación de recurrencias

↓

Patrón candidato

↓

Validación metodológica

↓

Patrón detectado
```

---

# Recurrencia

La recurrencia constituye una condición necesaria para la detección.

Un único acontecimiento no genera un patrón.

La recurrencia puede manifestarse mediante:

- repetición;
- persistencia;
- reaparición;
- estabilidad estructural;
- evolución consistente.

---

# Coherencia

Además de recurrencia, debe existir coherencia.

Las observaciones utilizadas deberán resultar compatibles entre sí.

La existencia de información contradictoria reduce el nivel de confianza del patrón.

No implica necesariamente su descarte.

---

# Evidencia

Las evidencias incrementan la calidad de la detección.

No crean patrones.

Únicamente fortalecen o debilitan la confianza asociada a ellos.

---

# Nivel de confianza

Toda detección incorpora un nivel explícito de confianza.

Este nivel depende de factores como:

- cantidad de información disponible;
- consistencia interna;
- cobertura del modelo;
- evidencia asociada;
- estabilidad temporal.

El nivel de confianza forma parte inseparable del patrón detectado.

---

# Confirmación

La detección no implica confirmación.

Todo patrón detectado permanece sujeto a revisión.

La aparición de nueva información puede:

- reforzar la hipótesis;
- debilitarla;
- modificarla;
- descartarla.

---

# Trazabilidad

Toda detección deberá poder reconstruirse.

Será posible identificar:

- las observaciones utilizadas;
- las hipótesis implicadas;
- las capacidades relacionadas;
- las fragilidades asociadas;
- las evidencias consideradas.

No se admitirán detecciones opacas.

---

# Independencia tecnológica

La metodología no impone ningún mecanismo concreto de implementación.

La detección podrá realizarse mediante:

- reglas;
- modelos probabilísticos;
- inteligencia artificial;
- técnicas híbridas.

Siempre que el resultado permanezca trazable y compatible con la metodología.

---

# Restricciones

La detección nunca podrá:

- sustituir el criterio metodológico;
- eliminar la incertidumbre;
- producir afirmaciones categóricas;
- ocultar el nivel de confianza;
- utilizar información ajena al modelo organizacional.

# Conclusión

La detección de patrones constituye un proceso continuo de inferencia sobre el modelo organizacional.

Su finalidad consiste en identificar regularidades suficientemente fundamentadas para enriquecer la comprensión sistémica de una organización, manteniendo en todo momento la incertidumbre, la trazabilidad y el nivel de confianza asociados a cada conclusión.
