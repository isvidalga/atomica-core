# Validación de Patrones

**Breadcrumb**

ATÓMICA → 70 · Patrones → Validación de Patrones

---

# Propósito

Este documento define cuándo un patrón organizacional puede considerarse suficientemente validado para formar parte del modelo organizacional.

No describe cómo se detecta un patrón.

No describe su ciclo de vida.

Describe únicamente los criterios mediante los cuales aumenta o disminuye la confianza asociada a un patrón.

---

# Principio fundamental

Detectar un patrón no implica que el patrón sea cierto.

Todo patrón constituye una hipótesis estructural cuya confianza evoluciona conforme aparece nueva información.

La validación nunca elimina completamente la incertidumbre.

Únicamente incrementa la confianza disponible.

---

# Objeto de validación

Lo que se valida no es la existencia de un evento.

Lo que se valida es la existencia de una regularidad organizacional suficientemente consistente para explicar un comportamiento observado.

---

# Fuentes de validación

La validación puede incrementarse mediante diferentes tipos de información.

Entre ellas:

- nuevas observaciones;
- diagnósticos sucesivos;
- evidencias documentales;
- evolución temporal;
- coherencia con otros patrones;
- intervención realizada y resultados observados.

Cada nueva fuente modifica el nivel de confianza del patrón.

---

# Factores de confianza

La confianza de un patrón puede depender de múltiples factores.

Por ejemplo:

- persistencia temporal;
- recurrencia;
- diversidad de evidencias;
- estabilidad entre diagnósticos;
- coherencia estructural;
- ausencia de contradicciones relevantes.

La metodología no exige que todos los factores estén presentes simultáneamente.

---

# Contradicciones

La aparición de información incompatible no elimina automáticamente un patrón.

Puede:

- reducir su confianza;
- mantenerla;
- iniciar una revisión.

La revisión forma parte del funcionamiento normal del modelo.

---

# Confirmación

Un patrón puede considerarse confirmado cuando la información disponible resulta suficientemente consistente para sostener la hipótesis con un nivel elevado de confianza.

La confirmación no implica certeza absoluta.

Implica únicamente que la evidencia acumulada hace razonable utilizar el patrón para interpretar la organización.

---

# Refutación

Un patrón puede ser refutado cuando la información disponible contradice de forma consistente la hipótesis previamente formulada.

La refutación constituye un resultado válido del proceso metodológico.

Eliminar una hipótesis incorrecta mejora el conocimiento del sistema.

---

# Revalidación

Los patrones nunca permanecen validados de forma permanente.

Toda nueva información puede modificar su nivel de confianza.

Por ello, la validación constituye un proceso continuo.

Nunca un estado definitivo.

---

# Relación con el modelo organizacional

El modelo organizacional incorpora patrones con distintos niveles de confianza.

La interpretación realizada por ATÓMICA deberá reflejar siempre dicha confianza.

Dos organizaciones pueden presentar el mismo patrón con niveles de validación completamente distintos.

---

# Restricciones

La validación de un patrón:

- no sustituye al juicio humano;
- no elimina la incertidumbre;
- nunca depende de una única observación;
- debe ser trazable;
- debe poder revisarse en cualquier momento.
