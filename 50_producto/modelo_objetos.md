# Modelo de Objetos

Estado: CANÓNICO

Versión: 1.0

---

# Propósito

El Producto representa exclusivamente objetos definidos por la Ontología.

Nunca crea objetos propios.

Toda representación visual constituye la manifestación de una entidad del dominio.

---

# Principio Fundamental

Toda representación del Producto corresponde exactamente a una entidad definida en la Ontología.

Si una representación no puede asociarse a una entidad del dominio, no pertenece a ATÓMICA.

---

# Jerarquía

Ontología

↓

Representación

↓

Pantalla

Nunca al contrario.

---

# Representación

Toda entidad del dominio podrá disponer de tres niveles de representación.

- Compacta.
- Expandida.
- Contextual.

No existirán niveles adicionales.

---

# Composición

Las pantallas no contienen componentes independientes.

Las pantallas constituyen composiciones de representaciones de entidades relacionadas.

---

# Consistencia

Una misma entidad conservará siempre:

- el mismo significado;
- la misma terminología;
- la misma jerarquía conceptual;
- las mismas reglas de representación.

Con independencia de la pantalla donde aparezca.

---

# Dependencias

Este documento depende de:

- 30_ontologia

No redefine ninguna entidad.

---

# Declaración

El Producto representa entidades.

La Ontología las define.

La Metodología construye el conocimiento sobre ellas.

El Producto únicamente lo hace visible.
