# Lenguaje del Producto

Estado: CANÓNICO

Versión: 1.0

---

# Propósito

El Lenguaje del Producto define las reglas mediante las cuales las entidades del dominio se representan dentro de ATÓMICA.

No define la Ontología.

No define la Metodología.

No define el diseño visual.

Define cómo el Producto hace visible el conocimiento.

---

# Principio Fundamental

Toda representación conserva el significado de la entidad que representa.

La representación nunca modifica el significado.

---

# Representación

Toda entidad dispone de tres niveles de representación.

- Compacta.
- Expandida.
- Profunda.

Cada nivel amplía la información del anterior.

Nunca modifica su significado.

---

# Contexto

Toda representación deberá proporcionar el contexto mínimo necesario para poder interpretarse.

Nunca se mostrará una entidad aislada de su contexto.

---

# Relaciones

Las entidades se representan mediante sus relaciones.

Las relaciones forman parte del conocimiento representado.

Nunca constituyen únicamente mecanismos de navegación.

---

# Incertidumbre

Toda representación cuya interpretación dependa del conocimiento disponible deberá mostrar explícitamente:

- confianza;
- evidencia disponible;
- fecha de actualización.

---

# Memoria

Siempre que resulte relevante, la representación permitirá comprender la evolución temporal de la entidad.

---

# Composición

Toda vista organiza las representaciones siguiendo el mismo orden lógico.

Pregunta.

↓

Estado.

↓

Relaciones.

↓

Explicación.

↓

Acción.

---

# Consistencia

Una misma entidad conservará siempre:

- el mismo significado;
- la misma terminología;
- el mismo comportamiento;
- las mismas reglas de representación.

Con independencia de la pantalla donde aparezca.

---

# Dependencias

Este documento depende de:

- 00_canon
- 30_ontologia

No redefine conceptos pertenecientes a dichos niveles.

---

# Declaración

El Producto no crea significado.

El Producto representa el significado definido por la Ontología y construido por la Metodología.
