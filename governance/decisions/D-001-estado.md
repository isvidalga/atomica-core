# D-001 · Reserva del término «Estado»

| Campo | Valor |
|--------|-------|
| Identificador | D-001 |
| Estado | CONGELADA |
| Versión | 1.0 |

# Decisión

La palabra **Estado**, utilizada sin calificativos dentro del Canon, designa exclusivamente el **Estado del Modelo**.

# Consecuencias

Queda prohibido utilizar "Estado" para designar:

- Estado Sistémico
- Estado del diagnóstico
- Estado de pantalla
- Estado de componente
- Estado SQL
- Estado HTTP
- Estado del proyecto

Estos conceptos deberán recibir denominaciones específicas en sus respectivos documentos.
