# D-003 · Independencia entre Estado y Confianza

| Campo | Valor |
|--------|-------|
| Identificador | D-003 |
| Estado | CONGELADA |
| Versión | 1.0 |

# Decisión

El Estado y la Confianza son dimensiones ortogonales.

La modificación de una no implica modificación de la otra.

# Consecuencias

Toda evolución de la confianza se regulará exclusivamente mediante el documento de Confianza.

El documento Estado no podrá redefinir esta relación.
