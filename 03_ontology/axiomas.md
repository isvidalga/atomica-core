---

# Propósito

Los axiomas constituyen las proposiciones fundamentales del Canon.

No se demuestran.

No derivan de otros documentos.

Todo documento posterior deberá ser compatible con ellos.

---

# A1 · Existencia del referente

Existe un referente organizacional independiente del Modelo.

El Modelo nunca crea el referente.

El Modelo nunca modifica el referente.

---

# A2 · Primacía de la representación

ATÓMICA nunca opera directamente sobre el referente.

Opera exclusivamente sobre representaciones construidas por el Modelo.

---

# A3 · Separación entre realidad y representación

La representación nunca constituye la realidad.

Toda representación es necesariamente parcial.

Toda representación es revisable.

---

# A4 · Falibilidad

Todo conocimiento producido por el Modelo puede ser revisado.

Ninguna representación es definitiva.

---

# A5 · Dependencia de la evidencia

Toda modificación del conocimiento requiere nueva evidencia admisible.

Sin nueva evidencia no existe nuevo conocimiento.

---

# A6 · Inmutabilidad histórica

Una representación consolidada nunca se modifica.

Toda revisión genera una nueva representación.

El histórico permanece inalterable.

---

# A7 · Persistencia

El conocimiento histórico nunca desaparece.

Puede dejar de ser vigente.

Nunca deja de existir.

---

# A8 · Temporalidad lógica

El Modelo evoluciona mediante una sucesión ordenada de Estados.

El orden lógico prevalece sobre el tiempo cronológico.

---

# A9 · Incertidumbre

Toda representación incorpora incertidumbre.

La incertidumbre nunca puede eliminarse completamente.

---

# A10 · Ortogonalidad

Estado y Confianza constituyen dimensiones independientes.

Modificar una no implica modificar la otra.

---

# A11 · No determinismo

El Modelo produce conocimiento.

Nunca determina decisiones.

Toda decisión pertenece exclusivamente al usuario.

---

# A12 · No normatividad

ATÓMICA no certifica.

No audita.

No juzga.

Representa el conocimiento disponible.

---

# A13 · Trazabilidad

Toda representación debe poder reconstruirse a partir de las observaciones y evidencias que la originaron.

---

# A14 · Continuidad

La evolución del conocimiento se expresa mediante una Trayectoria.

Toda Trayectoria conserva el histórico de los Estados que la componen.

---

# A15 · Conservación semántica

Todo concepto canónico mantiene exactamente el mismo significado en todo el Canon.

Ningún documento puede redefinir un concepto previamente congelado.

---

# Consecuencias

De estos axiomas derivan:

- Ontología
- Epistemología
- Metodología
- Modelo de datos
- Instrumento
- Interfaz

Todo el Canon depende de estos axiomas.

---

# Restricciones

Ningún documento podrá:

- contradecir un axioma;
- modificar un axioma;
- introducir excepciones a un axioma.

Toda modificación de este documento implica una nueva versión mayor del Canon.
