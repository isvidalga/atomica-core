# Propósito

Este documento constituye la única fuente de verdad para el desarrollo de ATÓMICA v2.

Toda funcionalidad deberá existir como una tarea dentro de este backlog antes de comenzar su implementación.

No se desarrollará ninguna funcionalidad fuera de este documento.
