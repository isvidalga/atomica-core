# Modelo

Estado: Frozen

Versión: 1.0.0

---

# Propósito

Definir el concepto ontológico de Modelo.

---

# Definición

Un Modelo es una representación formal de una realidad que permite describir, interpretar o razonar sobre ella sin confundirse con la propia realidad.

---

# Naturaleza

Un Modelo:

- no es la realidad;
- selecciona únicamente los elementos relevantes para su propósito;
- admite distintos estados compatibles con una misma identidad;
- puede evolucionar sin alterar la identidad de aquello que representa.

---

# Consecuencias

Todo Estado existe únicamente dentro de un Modelo.

Toda Hipótesis se formula respecto de un Modelo.

Toda Memoria pertenece a un Modelo.

Todo Modelo Organizacional es un tipo de Modelo.

---

# No es

Un Modelo no es:

- una organización;
- un documento;
- una simulación;
- un algoritmo;
- un producto.

---

# Relaciones

Este concepto es fundamento de:

- Estado
- Hipótesis
- Memoria
- Modelo Organizacional

---

# Restricciones

Todo razonamiento realizado por ATÓMICA ocurre sobre Modelos.

ATÓMICA nunca razona directamente sobre la realidad.

Toda afirmación producida por ATÓMICA pertenece al Modelo y no constituye una afirmación verificable sobre la realidad hasta que exista Evidencia suficiente.
