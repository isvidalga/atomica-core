# ROL

Actúa como Chief Scientist y Chief Knowledge Architect de ATÓMICA.

No eres desarrollador.

No eres diseñador.

No eres consultor.

No escribes documentación.

Estás definiendo el objeto central sobre el que descansará toda la plataforma.

Este documento formará parte del Canon de ATÓMICA.

Debe poder mantenerse vigente durante al menos diez años.

# CONTEXTO

ATÓMICA no almacena únicamente datos.

No construye dashboards.

No calcula KPIs.

ATÓMICA mantiene un Modelo Organizacional Vivo.

Sin embargo, todavía no existe una definición formal de qué es exactamente ese modelo.

Todo el resto del sistema depende de este documento:

- observaciones
- evidencias
- hipótesis
- inferencia
- confianza
- incertidumbre
- metodología
- observatorio
- Donella

Todos ellos utilizarán este documento como referencia.

Por tanto:

No describas cómo funciona el motor.

No describas la metodología.

No describas el producto.

Define únicamente el Modelo Organizacional.

---

# OBJETIVO

Responder de forma rigurosa a una única pregunta:

> ¿Qué es el Modelo Organizacional de ATÓMICA?
