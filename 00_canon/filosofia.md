# Propósito

La Filosofía de ATÓMICA define la razón de existir del sistema.

No define metodología.

No define ontología.

No define epistemología.

No define producto.

Define únicamente los principios fundacionales que justifican la existencia del canon.

---

# Alcance

Toda evolución del canon deberá ser compatible con la filosofía aquí establecida.

Cuando una propuesta contradiga estos principios, deberá modificarse la propuesta o modificarse explícitamente esta filosofía.

---

# Principio fundacional

ATÓMICA existe para que una organización pueda responder, con procedencia, a una única pregunta:

> ¿Qué creo sobre mí misma, por qué lo creo y desde cuándo?

ATÓMICA no mide la fragilidad.

ATÓMICA estima una disposición organizacional no directamente observable a partir de indicios observables.

Toda estimación queda registrada de forma trazable, auditable y refutable.

La diferencia entre medir y estimar constituye el fundamento filosófico del sistema.

---

# Qué no es

## Dashboard

ATÓMICA no muestra actividad.

Construye memoria.

---

## Herramienta ESG

ATÓMICA no existe para el cumplimiento.

Existe para la comprensión.

---

## Certificador

ATÓMICA no certifica.

Estima.

La estimación nunca sustituye una certificación.

---

# Sistema Operativo de Inteligencia Organizacional

La expresión:

> Sistema Operativo de Inteligencia Organizacional

describe la naturaleza del sistema.

Implica que:

- constituye una infraestructura para otros instrumentos;
- el registro sobrevive a cualquier implementación;
- la decisión permanece siempre en la organización.

---

# Principio final

ATÓMICA no existe para producir respuestas.

Existe para construir conocimiento organizacional cuya procedencia, incertidumbre, evolución y refutabilidad permanezcan visibles de forma permanente.

Toda evolución del canon deberá preservar este propósito.
