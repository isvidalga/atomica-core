## Ley 3 · Límites

Todo sistema opera dentro de márgenes de funcionamiento.

La capacidad adaptativa nunca es ilimitada.

Cuando un sistema se aproxima a sus límites comienzan a aparecer tensiones.

Cuando dichos límites se superan, el sistema entra en un estado de fragilidad.

### Implicaciones

La ausencia de incidentes visibles no implica que el sistema opere dentro de márgenes seguros.

Las tensiones constituyen señales tempranas de aproximación a los límites del sistema.

### Restricción

Ninguna inferencia puede asumir que un sistema es estable únicamente porque no presente fallos observables.
