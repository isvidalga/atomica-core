# Regla de precedencia

ATÓMICA se compone de dos repositorios con responsabilidades distintas.

- atomica-core → autoridad metodológica.
- atomica-app → implementación del producto.

Toda discrepancia entre ambos se resuelve automáticamente en favor de atomica-core.

La aplicación puede incumplir el canon.
El canon no se considera incorrecto por estar desalineado con la aplicación.

Las auditorías deberán clasificar estas incidencias como:

APP-001 · Desviación de implementación

Nunca como error del canon, salvo que exista una contradicción interna dentro de atomica-core.
