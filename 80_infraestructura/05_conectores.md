# Conectores

Estado: CANÓNICO

Versión: 1.0

---

# Propósito

Los conectores permiten incorporar información externa al Modelo Vivo.

Nunca sustituyen el diagnóstico.

Nunca generan Estado Sistémico.

Solo aportan nuevas observaciones.

---

# Principios

Toda integración debe cumplir:

- autenticación segura
- permisos mínimos
- sincronización incremental
- trazabilidad
- posibilidad de desconexión

El modelo debe seguir funcionando aunque desaparezca cualquier conector.

# Estado

Cada conector mantiene:

- conectado
- última sincronización
- errores
- permisos concedidos

---

# Uso

Los conectores solo enriquecen el modelo.

Nunca son obligatorios.

La plataforma debe funcionar sin ninguno.
