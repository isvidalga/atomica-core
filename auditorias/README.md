# Auditorías del repositorio

Estado: Histórico

Las auditorías documentan verificaciones realizadas sobre versiones concretas
del repositorio.

No forman parte del Canon.

No definen la metodología.

No sustituyen los documentos Frozen.

Su finalidad es:

- verificar coherencia;
- localizar inconsistencias;
- justificar cambios posteriores;
- mantener trazabilidad arquitectónica.

Cada auditoría referencia explícitamente:

- commit auditado;
- alcance;
- método;
- evidencias;
- determinación;
- impacto sobre auditorías anteriores.
