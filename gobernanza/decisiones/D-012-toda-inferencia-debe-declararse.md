# D-012 · Toda Inferencia debe Declararse

Estado: CONGELADA

Versión: 1.0.0

Ubicación:

gobernanza/decisiones/D-012-toda-inferencia-debe-declararse.md

---

# Propósito

Resolver definitivamente el tratamiento de las inferencias dentro de ATÓMICA.

---

# Decisión

ATÓMICA distinguirá explícitamente entre:

- observaciones;
- inferencias;
- estimaciones.

Una inferencia nunca podrá presentarse como si fuese una observación.

Toda inferencia deberá declararse como tal.

---

# Alcance

Esta decisión afecta a:

- modelos;
- IA;
- informes;
- visualizaciones;
- explicaciones;
- API.

---

# Consecuencias

Toda inferencia deberá poder relacionarse con:

- las observaciones utilizadas;
- las reglas aplicadas;
- la versión metodológica correspondiente.

Si alguno de estos elementos no puede identificarse, la inferencia carece de validez normativa.

---

# Restricciones

No se permitirá:

- presentar inferencias como hechos;
- ocultar el origen de una inferencia;
- utilizar inferencias sin trazabilidad.
