# D-013 · El Conocimiento nunca se Sobrescribe

Estado: CONGELADA

Versión: 1.0.0

Ubicación:

gobernanza/decisiones/D-013-el-conocimiento-nunca-se-sobrescribe.md

---

# Propósito

Resolver definitivamente el tratamiento de la evolución del conocimiento registrado por ATÓMICA.

---

# Decisión

El conocimiento nunca será sustituido mediante sobrescritura.

Toda evolución deberá registrarse como una nueva versión del conocimiento existente.

La historia permanece íntegra.

---

# Alcance

Esta decisión afecta a:

- observaciones;
- hipótesis;
- estimaciones;
- evidencias;
- modelos;
- interpretaciones.

---

# Consecuencias

Toda modificación deberá conservar:

- el estado anterior;
- el estado posterior;
- la fecha;
- la procedencia;
- la justificación del cambio.

El conocimiento vigente nunca elimina el conocimiento previo.

---

# Restricciones

No se permitirá:

- sobrescribir registros históricos;
- eliminar versiones anteriores;
- perder la trazabilidad de una evolución.
