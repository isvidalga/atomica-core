# D-012 · Toda Inferencia y Explicación debe ser Derivable

Estado: CONGELADA

Versión: 2.0.0

Ubicación:

gobernanza/decisiones/D-012-inferencia-explicacion-derivable.md

---

# Propósito

Resolver definitivamente el tratamiento de las inferencias y explicaciones generadas por ATÓMICA.

---

# Decisión

ATÓMICA distinguirá explícitamente entre:

- observaciones;
- inferencias;
- estimaciones;
- explicaciones.

Las inferencias y las explicaciones nunca podrán presentarse como observaciones.

Toda inferencia y toda explicación deberán derivarse exclusivamente del conocimiento registrado.

---

# Alcance

Esta decisión afecta a:

- IA;
- modelos;
- informes;
- interfaces;
- API;
- visualizaciones;
- asistentes.

---

# Consecuencias

Toda inferencia o explicación deberá poder reconstruirse indicando:

- las observaciones utilizadas;
- las reglas aplicadas;
- la versión metodológica correspondiente.

Las explicaciones nunca constituirán una fuente independiente de conocimiento.

Si alguno de estos elementos no puede identificarse, la inferencia o explicación carece de validez normativa.

---

# Restricciones

No se permitirá:

- presentar inferencias como hechos;
- ocultar el origen de una inferencia;
- introducir conocimiento no derivable;
- generar explicaciones incompatibles con el registro;
- alterar el significado del conocimiento durante su explicación.
