# D-006 · El Canon precede a la Implementación

Estado: CONGELADA

Versión: 1.0.0

Ubicación:

governaza/decisiones/D-006-canon-precede-implementacion.md

---

# Propósito

Resolver de forma definitiva la relación de autoridad entre el Canon y cualquier implementación.

---

# Decisión

El Canon constituye la autoridad normativa del sistema.

Toda implementación deberá adaptarse al Canon.

El Canon nunca se adaptará a una implementación existente.

---

# Alcance

Esta decisión afecta a:

- atomica-core;
- atomica-app;
- cualquier implementación presente o futura del sistema.

---

# Consecuencias

Una discrepancia entre el Canon y una implementación constituye una desviación de implementación.

Nunca constituye una modificación implícita del Canon.

Toda modificación conceptual deberá producirse primero en el Canon.

Solo posteriormente podrá trasladarse a las implementaciones correspondientes.

---

# Restricciones

Ninguna implementación podrá redefinir:

- conceptos;
- ontología;
- epistemología;
- metodología;
- taxonomías;
- lenguaje oficial.
